# Real club replacement baseline

Audited source catalog: 2524 clubs.

- factual/explicit clubs preserved: 617
- generated filler slots to replace: 1907
- replacement policy: one real Brasfoot patch club per filler slot
- ID policy: the real club inherits the legacy numeric slot ID
- crest policy: original PNG from the Brasfoot patch, no generic reshaping

The CSV is the immutable compatibility baseline used to build the one-to-one replacement plan.
It intentionally contains no external sporting data and does not alter players.
